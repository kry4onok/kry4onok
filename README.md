## Проекты

### [ConversionReportSystem](https://github.com/kry4onok/ConversionReportSystem)

Сервис на .NET 10 для отчётов о конверсии просмотров в покупки. Принимает запросы через Kafka, собирает их в пакеты и отдаёт результаты через gRPC. Хранит отчёты в PostgreSQL и кэширует результаты в Redis.
